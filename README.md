# 肝肝鼠

肝肝鼠是由 HaJi-Lan 维护的独立二次开发项目，基于OnmyojiAutoScript (https://github.com/nearaura/OnmyojiAutoScript)

Rust 原生桌面程序，统一管理上游 OAS 的 Python 任务、配置和日志。

具体功能与OAS大同小异，不过根据个人需求，只留下了部分肝肝内容并进行优化

已移除日常任务、每周任务、阴阳寮分类，以及英杰试炼、寻找协作任务。个人突破保留独立功能，移至肝帝专属分类，并继续与绘卷模式共享配置。

设置可在底部统一保存（Ctrl+S），切换任务或配置时保留未保存的草稿；点击“保存并启动配置”会先保存该配置的修改，全部成功后再启动。支持任务分类筛选与设置搜索、按需展开说明，以及日志筛选和复制。

界面分为任务选择、参数设置、正在执行的任务和日志四区。采用浅色灰白配色与紧凑布局，左侧任务、中间参数，右侧上下分为执行与日志；左右分区宽度与右侧执行/日志分界均可拖动调整；执行区显示实际运行任务、绘卷当前阶段、执行时长及后续调度任务。

通用战斗配置仅显示“锁定阵容”和“战斗时随机点击或者随机滑动”，绘卷集合页中的探索与突破战斗设置保持一致。

参数面板已移除“执行任务前切换御魂”，绘卷集合页中对应的御魂切换设置一并隐藏。

调度器面板仅显示“下一次运行时间”“任务优先级”“随机延迟时间”，任务标题旁保留启用开关。

参数面板已移除金币、经验的 50% / 100% 加成开关，各任务与绘卷集合页保持一致。

更新构建详情保存在 `runtime/build-latest.log` 和 `runtime/update-build.log`。构建失败时保留旧程序，再次更新会继续完成；也可关闭软件后运行 `GanganMouse.exe --update` 完成更新。
